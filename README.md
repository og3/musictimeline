# 音楽年表 — プロトタイプ

Steamのフレンドアクティビティを参考にした、PC優先の静的音楽年表です。HTML・CSS・JavaScriptとCSVだけで動き、ビルドや外部APIは不要です。

## 起動

### すぐに試す

別添の `music-timeline-preview.html` をブラウザで開いてください。配布時点のCSV・CSS・JavaScriptを埋め込んだ確認用ファイルです。サーバーは不要です。ブラウザによってはfile URLの保存が制限されます。

### 開発・GitHub Pages用

このフォルダーで次を実行し、表示されたポートをブラウザで開きます。

```sh
python -m http.server 8000
```

通常は http://localhost:8000/ です。index.htmlを直接ダブルクリックするとCSVの取得が制限されるため、こちらはHTTP経由で開いてください。

## GitHub Pagesへの配置

1. `index.html`、`style.css`、`app.js`、`artists.csv`、`.nojekyll` を同じ階層に置いてリポジトリにpushします。
2. リポジトリのSettings → Pagesで対象ブランチと配置フォルダーを指定します。
3. 公開URLを開き、検索と保存を確認します。

相対パスのため、リポジトリ名を含むURLでも動きます。noindexを設定済みです。検索掲載を希望する場合はindex.htmlのrobotsメタタグを削除してください。noindexはアクセス制限ではありません。

この納品ではGitHubへのpush・公開は実施していません。

## 操作

- 初期状態は空の年表です。生まれ年は任意で、未入力でも使えます。
- 名前・日本語別名・略称で検索するか、「収録アーティスト」から選びます。
- 検索欄の上下キーとEnterでも追加できます。
- 行のつまみをドラッグすると並べ替えられます。
- 名前または「⋯」から、活動年・出典・本人との時代差・上下移動・削除を開けます。
- 名前の長押しでも同じダイアログを開けます。
- 削除は8秒以内なら元に戻せます。
- 年表の時間軸は横スクロールでき、全行が同期します。西暦・本人の行は縦スクロール時に追従します。
- 変更はlocalStorageへ保存されます。同じブラウザ・同じオリジン・同じ配置先で復元します。別端末や確認用HTMLと公開サイト間では共有されません。
- リセットは確認後、生まれ年と追加したアーティスト・順序を消します。他アプリの保存領域は消しません。

## CSVの編集

`artists.csv` がアーティスト情報の唯一の管理ファイルです。1行1組、UTF-8、以下のヘッダーを使います。

```csv
id,name,start_year,end_year,status,aliases,genres,countries,source_url
```

- 必須：id、name、start_year、status。idは一意で、名前を修正しても変更しないでください。
- status：`active`（活動中）、`ended`（終了）、`unknown`（終了年不明）。
- end_year：endedの場合のみ必須。active・unknownの場合は空欄。
- 任意：aliases、genres、countries、source_url。空欄でも名前検索と年表が動きます。
- 別名・ジャンル・国・出典が複数ある場合は `|` で区切ります。
- カンマを含むセルはダブルクォートで囲み、セル内のダブルクォートは2個重ねてください。
- 国・ジャンルは同じ綴りに統一します。別辞書ファイルは不要です。
- 追加ファイルを要求することなく、新しい行を追加して再公開できます。

## サンプルデータについて

日本・イギリス・アメリカ各10組、合計30組（B'zなどのデュオを含む）。2026年10月5日にWikipedia英語版のOrigin・Years active・Genres等を参照し、CSVのsource_urlに個別記事のリンクを記載しています。ジャンルは列挙されたものから一部を選び、表記を統一しています。日本語名・略称は検索用に補っています。

Wikipediaの本文・画像は転載せず、名称・年・国などの項目を整理しています。出典は各行の操作ダイアログから開けます。Wikipediaの情報は更新・修正され得るため、本データは確認時点のサンプルとして扱ってください。

### 年代の扱い

- 活動期間は休止期間を含む一本線です。全期間に継続して活動したことや、同じメンバー構成を示すものではありません。
- 年は原則として参照記事のYears active欄に従います。デビュー年とは限りません。
- The Policeは再結成を含み1977〜2008年、Linkin Parkとサザンオールスターズは休止を含んで現在までの表示です。
- Led ZeppelinはYears active欄の主要期間1968〜1980年を採用し、脚注にある単発再集結は含めていません。Nirvanaなども単発の記念演奏・再発を活動継続とはみなしません。
- The Kinksは参照欄の1962〜1997年、Red Hot Chili Peppersは1982年開始、サザンオールスターズは1975年開始、CCRは1968年開始を採用しています。前身バンドや結成の定義により、他の資料の年と異なる場合があります。
- 現在年はブラウザの日付から計算します。activeの状態自体は自動更新されないため、CSVの定期確認が必要です。

## ファイル構成

- index.html：画面
- style.css：PC・スマートフォン共通スタイル
- app.js：検索、CSV解析、描画、保存、各操作
- artists.csv：30組のサンプルデータ

- music-timeline-spec.md：元の仕様書
- README.md：本書

依存ライブラリ・外部フォント・外部画像・解析タグはありません。ダイアログ等には現行ブラウザの標準機能を使います。

## 確認結果

Chromiumで1440px・390px・360pxの表示と、検索（別名・キーボード）、生まれ年、保存・再読み込み、並べ替え（ドラッグ・メニュー）、削除・取り消し、リセット・キャンセル、追従表示、横スクロール同期を確認しました。空欄の任意項目、引用符・カンマを含むCSV、同年開始終了、不明状態、重複追加、不正な年、保存拒否、CSV取得失敗と再試行、確認用HTMLの単体起動も確認しています。

スマートフォンはブラウザの画面幅・タッチ設定を使った確認です。iOS Safari・Android実機での長押し／ドラッグ、およびGitHub Pages上での最終確認は未実施です。
